⚙️ How it Works

The Agent Service receives the user prompt and acts as the orchestrator. It prepares the context, loads the tool catalog, and structures the system prompt to enforce guardrails before calling the LLM.

🔗 How it Communicates

  • Receives: Chatbot
  • Talks to: LLM
  • Sends to: BFF Exchange

[CH] Chatbot ➔ [👤] Agent ➔ [ML] LLM
