Annotations

Configured topology, not live health. The map is derived from repo declarations. It does not inspect the cluster or assert that a pod is running.
mTLS varies by deployment. Local MCP mTLS is opt-in. The checked-in Kubernetes manifests do not declare a workload mTLS setting for these service hops.
NetworkPolicy scope. The checked-in ai-demo-internal policy permits ingress from pods in ai-demo and ingress-nginx; egress allows the namespace, DNS, and public TCP 80/443, with AWS metadata addresses excluded.
Standards badges are references. A link describes the standard relevant to a flow; it is not a conformance result. RFC 8705 covers OAuth client mTLS and certificate-bound tokens; it does not define generic workload mTLS or SPIFFE.

Review mock only. Planned implementation will use React Flow and the repository network topology, Compose services, Kubernetes services, ingress, and network policy as its evidence sources.
