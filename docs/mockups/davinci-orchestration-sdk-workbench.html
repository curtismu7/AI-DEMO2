1. Start the flow
The selected policy can return collectors or complete immediately when PingOne already has a session.
const node = await client.start({ query });
// Check node.status before rendering collectors.


2. Submit a collector answer
Each field updates its SDK collector as the user types. Then next() advances DaVinci and waits for the response.
client.update(collector)(value);
const nextNode = await client.next();


3. Wait for the callback
Flow completion is not the same as an app session. Wait for the authorization callback and BFF session confirmation.


4. Sign out safely
The post-logout redirect URI must be registered on the PingOne application. An unregistered URI fails with INVALID_VALUE.
await signOutOfPingOne(config);


5. P1 collectors and ACR routing
Render by collector type and category; surface unsupported collectors. The ACR value selects between the two DaVinci policies.
