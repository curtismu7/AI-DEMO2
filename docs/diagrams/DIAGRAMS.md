## Exporting to Other Tools (Lucidchart, draw.io, mermaid.live)

Each of the three nav diagram pages (System Diagram, Overview Diagram,
Sequence Diagram) has an **Export** bar with direct downloads. The same files
are served under `/architecture/` and generated by `npm run build:diagrams`:

| Diagram | Mermaid | PNG / SVG | draw.io / Lucid |
| --- | --- | --- | --- |
| Full architecture | `architecture.mmd` | `overview2.png` / `overview2.svg` | `architecture.drawio` |
| Clean overview | `architecture-simple.mmd` | `overview.png` | `architecture-simple.drawio` |
| Token-exchange sequence | `i4ai-ref-arch.mmd` | `token-flow.png` | — (sequence: use Mermaid paste, below) |

**Lucidchart** (two routes):

1. **Editable shapes** — File > Import > draw.io, pick the `.drawio` file. The
   `.drawio` exports are generated from the `.mmd` sources by
   `scripts/export-drawio.mjs` with a simple grid layout — expect to re-arrange
   after import; nodes, labels, groups, and edges all come across editable.
2. **Diagram as code** — Insert > Diagram as code > Mermaid, paste the `.mmd`
   contents. Lucid renders it natively (flowcharts AND sequence diagrams,
   Mermaid 11.x) and re-renders on code edits. Shapes are not draggable in
   this mode.

**draw.io / diagrams.net**: open the `.drawio` directly, or Insert > Advanced >
Mermaid and paste the `.mmd` to get editable shapes.

**Present-only**: use the PNG (all decks/wikis) or SVG (crisp at any zoom).

## How to Use Draw.io Files

1. Right-click a download link and select "Save Link As"
2. Save the `.drawio` file to your local machine
3. Open in [app.diagrams.net](https://app.diagrams.net) or VS Code with the Draw.io extension
4. Edit as needed for your documentation

## How to Regenerate Mermaid PNGs

Mermaid `.mmd` source files are the source of truth. The rendered PNGs under
`demo_api_ui/public/architecture/` (e.g. `overview2.png`, `token-flow.png`) are
**not** auto-regenerated when the `.mmd` files change — a separate render step
is required:

```bash
npm run build:diagrams
```

or from the UI: `/architecture/system` → Regenerate.

## RFC Annotations

All diagrams include comprehensive RFC annotations for:

### Authentication & Authorization

- **RFC 6749** - OAuth 2.0 Authorization Framework
- **RFC 7636** - Proof Key for Code Exchange (PKCE)
- **RFC 8628** - CIBA (Client Initiated Backchannel Authentication)
- **RFC 8693** - OAuth 2.0 Token Exchange
- **RFC 8707** - Resource Indicators
- **RFC 9728** - OAuth for MCP (Model Context Protocol)

### Security & MFA

- **deviceAuthentications API** - PingOne MFA Implementation
- **STEP_UP_ACR_VALUE** - Multi-factor authentication policy
- **Session Management** - Step-up verification with TTL
