MCP Server — OAuth Configuration

Illustrative config UI for banking-mcp (demo_mcp_resource_server), the MCP server registered with PingOne Privilege as an Agentic App. This page is a design mock only — no data here is saved or wired to a real gateway.

⚠️
Auth Mode: OAuth is a known platform blocker, not a config gap. It was already tried against the live Privilege gateway on 2026-09-09 and made discovery worse than Auth Mode None — a tokenless initialize 401s, the gateway's own /banking-mcp/token endpoint rejects PingOne client credentials, and even a correctly-signed PingOne bearer 401s with token_not_found (the gateway checks its own internal token registry, not the token's signature). See privilege/CURRENT-CONFIGURATION.md. This form exists to show the shape of the config, not to re-attempt the fix.
