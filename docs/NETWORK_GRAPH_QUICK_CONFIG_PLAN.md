# Dev Plan: Live Network Graph (Cytoscape.js) in Agent Quick Config

**Status:** Approved plan, not yet implemented
**Date:** 2026-09-23

## Goal

Render a live, interactive network topology graph (Cytoscape.js) of the demo's services with real-time health status, surfaced **only** as an Agent Quick Config surface — embedded, pop-out, or off. No standalone page/route.

## Reuse (no new plumbing)

- **Topology data:** `demo_api_ui/src/service-topology.json` (read-only; generated by root `scripts/gen-service-topology.js` — never hand-edit).
- **Live status:** existing BFF endpoints in `demo_api_server/routes/health.js` — `/health/services` (per-service matrix), `/health/mcp-gateway`. No BFF changes.
- **Surface toggle:** existing `none / embedded / popout / both` via `SurfaceSelector` (`AIAgent.js` `SURFACE_OPTIONS` ~line 136) + `src/utils/surfacePrecedence.js`, persisted to localStorage.
- **Pop-out mechanism:** `src/components/FloatingPanel.jsx` → `PopOutPortal` (`window.open` + "Bring back"); tests already assert "Pop out Quick Config".
- **Fetch:** `src/services/bffAxios.js` (session cookie, `withCredentials: true`).

## Implementation

1. **Dependency:** `npm i cytoscape` in `demo_api_ui`.
2. **New shared component:** `src/components/NetworkStatusGraph.jsx` + `.css`
   - Nodes/edges from `service-topology.json`; tier classes (UI, BFF, MCP gateway, OAuth, PingOne) for colors; edge labels with port/scheme.
   - Poll `/health/services` (+ `/health/mcp-gateway`) every ~15s; map status → node ring color (healthy / degraded / down).
   - **Fallback:** if health fetch fails (e.g., pop-out window lacks session cookie), render static topology only.
   - Interactions: pan/zoom, node tap → detail tooltip (host, port, scheme, status).
3. **Quick Config integration** in BOTH `AIAgent.js` (panel ~lines 10198–10283) and `AIAgentFull.js` (~lines 9902–9905):
   - Add "Network status" section rendering `NetworkStatusGraph` when surface = embedded; pop-out renders via `PopOutPortal`.
   - Register surface via existing `SURFACE_OPTIONS` / localStorage helpers — one shared component, no logic copies.
4. **Tests (Vitest):** surface toggle states (none / embedded / popout); health-status → styling mapping; static fallback on failed health fetch.

## Verification

- `cd demo_api_ui && npm ci && npm run test:unit && npm run build` (mandatory UI build gate).
- `npm run topology:verify` only if the topology snapshot must be regenerated (shouldn't be — read-only usage).
- Regression-guard applies (touches `demo_api_ui`); no OAuth/session/token-exchange code touched. Emoji allowlist preserved.

## Decisions made

- Pop-out window without a session → static topology + best-effort health (approved).
- No standalone page — Quick Config surface only (approved).
