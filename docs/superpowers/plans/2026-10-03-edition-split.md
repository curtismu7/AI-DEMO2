# Edition Split (P1-AI-DEMO / PF-AI-DEMO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate two private standalone repos from AI-DEMO2 (`P1-AI-DEMO`: PingOne issues tokens; `PF-AI-DEMO`: PingFederate issues tokens, PingOne behind it), each on its own new PingOne environment, without changing AI-DEMO2's behavior.

**Architecture:** AI-DEMO2 stays the only place code is written. A manifest per edition (`editions/*.json`) plus one export script (`scripts/export-edition.js`) copies tracked files from a git ref, drops the other edition's paths, pins `OAUTH_PROVIDER`, and refuses to finish unless gates pass inside the exported tree. Phases 0-2 make a fresh PingOne environment and a fresh PingFederate reproducible, because an edition that cannot be stood up from scratch cannot ship.

**Tech Stack:** Node >= 22 (CommonJS scripts, `node --test`, matching `scripts/check-auth-requirements.js`), bash, gitleaks, existing `npm run` gates, `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-10-03-edition-split-design.md`

## Global Constraints

- AI-DEMO2 behavior is unchanged: nothing is deleted from AI-DEMO2; the `OAUTH_PROVIDER` runtime switch stays.
- Editions are generated, one-way. Nobody edits them by hand.
- Repos are private and named exactly `P1-AI-DEMO` and `PF-AI-DEMO`.
- Each edition has its own new PingOne environment. Nothing in an edition may reference AI-DEMO2's environment ID, worker apps, users, DaVinci flows, Authorize policies or vault secrets.
- PF edition may keep every PingOne service (directory, MFA, Authorize, DaVinci, Protect, Privilege).
- Exports use `git archive`/`git ls-files` from a ref, never a filesystem walk: no `.env`, vault data, or gitignored files; no history.
- Emoji allowlist (`REGRESSION_PLAN.md` section 0) applies to any UI text touched.
- Edit, test and commit only in a worktree; stage files explicitly; never `git add -A`.
- Default deploy target is local Docker only. Never touch `ping-devops-cmuir` or other remote environments. The AI-DEMO2 PingOne environment is read-only for this project.
- Never print secret values; secrets live in the vault, not Git.
- A new top-level dir (`editions/`) must be added to `scripts/root-allowlist.txt` in the same commit (`npm run root:allowlist:check`).

## Review Focus

1. Manifest path that matches nothing (typo): export must fail, not silently remove nothing.
2. Target dir inside the source repo, non-empty, or equal to it: export must refuse before writing.
3. Export from a dirty or untracked working tree: must copy only what the ref tracks (no `.env`, no `data/persistent`, no vault files).
4. AI-DEMO2's PingOne environment ID or client IDs appearing anywhere in an exported tree (docs, snapshots, compose, k8s): gate must fail.
5. A removed file still imported by retained code: the exported UI build or scoped BFF tests must fail the export.

```js
#!/usr/bin/env node
/* Generate an edition (P1-AI-DEMO / PF-AI-DEMO) from a git ref. See
 * docs/superpowers/specs/2026-10-03-edition-split-design.md. */
const fs = require('node:fs');
const path = require('node:path');
const { execFileSync } = require('node:child_process');

const git = (cwd, ...a) => execFileSync('git', a, { cwd, maxBuffer: 1 << 28 });

function exportEdition({ manifest, ref, srcRepo, dest }) {
  const src = fs.realpathSync(srcRepo);
  const out = path.resolve(dest);
  if (out === src || out.startsWith(src + path.sep)) throw new Error(`dest ${out} is inside the source repo`);
  if (fs.existsSync(out) && fs.readdirSync(out).length) throw new Error(`dest ${out} is not empty`);

  const sha = git(src, 'rev-parse', ref).toString().trim();
  const files = git(src, 'ls-tree', '-r', '-z', '--name-only', sha).toString().split('\0').filter(Boolean);

  const used = new Set();
  const isRemoved = (f) => manifest.remove.some((p) => {
    const hit = p.endsWith('/') ? f.startsWith(p) : f === p;
    if (hit) used.add(p);
    return hit;
  });
  const keep = files.filter((f) => !isRemoved(f));
  for (const p of manifest.remove) if (!used.has(p)) throw new Error(`remove pattern "${p}" matched nothing`);

  for (const f of keep) {
    const to = path.join(out, f);
    fs.mkdirSync(path.dirname(to), { recursive: true });
    fs.writeFileSync(to, git(src, 'show', `${sha}:${f}`));
  }
  fs.writeFileSync(path.join(out, '.edition.json'),
    JSON.stringify({ name: manifest.name, provider: manifest.provider, sourceSha: sha, dropUseCases: manifest.dropUseCases }, null, 2) + '\n');
  return { copied: keep.length, removed: files.length - keep.length };
}

module.exports = { exportEdition };

if (require.main === module) {
  const [, , which, dest, ...rest] = process.argv;
  if (!['pingone', 'pingfederate'].includes(which) || !dest) {
    console.error('usage: export-edition.js <pingone|pingfederate> <dest> [--ref main]'); process.exit(2);
  }
  const ref = rest[rest.indexOf('--ref') + 1] || 'main';
  const repo = path.resolve(__dirname, '..');
  const manifest = JSON.parse(fs.readFileSync(path.join(repo, 'editions', `${which}.json`), 'utf8'));
  console.log(exportEdition({ manifest, ref, srcRepo: repo, dest }));
}
```
