## 4. Traps the next agent will hit (learned the hard way)

1. **Pre-commit blocks source commits from the main checkout.** All commits must come from a worktree: `git worktree add .claude/worktrees/<name> -b <branch>`. Exemptions: `.claude/**`, `CLAUDE.md`, `REGRESSION_PLAN.md`, `AGENTS.md`. (`.husky/pre-commit` enforces this.)
2. **Step-verification ledger churn** — running any `tests/stepVerification*` suite after ~15 days re-stamps `checkedAt` on 600+ files. The ledger has a 15-day refresh window; on 2026-09-26 the stored dates (2026-08-29) crossed it. **`git checkout -- demo_api_server/data/step-verification`** after test runs; don't commit the churn.
3. **Node 26 vs 22** — `@a2a-js/sdk` is ESM-only; Node 26 + jest fails to require it. Use the node@22 PATH above.
4. **`jest -t <name>` + `it.each(cases)` with an empty array throws** — the chip-reachability suite now guards its `it.each` behind `if (cases.length > 0)`.
5. **Root `.env` beats `demo_api_server/.env`** (server.js documented precedence) — several privilege-client tests must derive expectations from `process.env` at runtime, not from constants.
6. **Console is mocked in tests** (`src/__tests__/setup.js`) — `VERBOSE_TESTS=true` to see logs; better: write debug output to a file from inside the test.
7. **Vitest ≠ jest** in `demo_api_ui` — different matchers; `npm run test:unit`, never jest.
8. **CI runs stack** on the single runner. Check `gh api …/actions/runs?status=queued` and cancel stale runs (`-X POST …/runs/<id>/cancel`) before waiting on a new PR's checks.
9. **SE cluster is shared** — `./run-pingaws.sh undeploy` when done. `k8s/create-secrets.sh` fails closed on any `.env`-vs-vault drift; the vault wins, always.
