15 / One request through the stack

One request, source-traced

A protected tool call passes six explicit boundaries.

1 · AskReact → BFF prompt with session cookie.
2 · CheckBFF validates session, selects LangChain runtime.
3 · RunBFF calls agent /run; AG-UI events stream back.
4 · ToolAgent calls BFF /internal/agent-tool.
5 · AuthorizeBFF exchanges token, calls PingGateway: permit · deny · approval.
6 · ShowResult + events return to UI and token-chain views.
Credential boundary: BFF holds browser tokens; the agent only requests tools via callback.

21 / Privilege AI Gateway

Privilege AI Gateway

JIT least-privilege tool policy and session recording at the MCP boundary.

What the gateway path adds

  • React page at /privilege-mcp-client; BFF relays MCP at /api/privilege-mcp/*.
  • User mode uses OAuth code + PKCE; simple mode uses a service client-credentials token.
  • MCP handshake and tool discovery: initialize, tools/list, then tools/call.
  • The gateway is a server to the BFF and a client to each backend; policy is applied between those sessions.
  • Per-application tool policy, just-in-time least privilege, and session recording.
  • BFF SSE events show OAuth phases, relayed calls and upstream responses.

Run with the opt-in Compose profile mcpgw: mcpgw-nginx fronts ping-mcpgw. Tenant and gateway console configuration are required. This is separate from PingGateway and the demo Node gateway.

31 / AI functionality

AI usage

Heuristics handle known commands. LLMs handle open text. Neither grants scope.

Intent routing

  • Heuristic phrase parser runs for known commands and chips.
  • LLM can return structured action intent for free-text requests.
  • Heuristic fallback keeps common flows available if the LLM route fails.
  • Prompt guard checks configured attack patterns before the LLM call.

Providers / local servers

  • Ping AI / Helix
  • OpenAI
  • Anthropic Claude
  • LM Studio and llama.cpp / oMLX local model modes
  • Ollama in Kubernetes profile; optional proxy fallback where configured

Reasoning and retrieval features

  • Multi-turn LangChain agent runs and conversation history
  • Alternate runtimes explored with OpenAI Agents SDK, Mastra and Pydantic AI
  • Protected code search / Code Explorer
  • Document RAG and knowledge-grounding paths
  • Reasoning/tool activity streamed through AG-UI and traces

Non-LLM enforcement

  • LLM output does not grant OAuth scope.
  • BFF, gateway and resource server validate identity, audience, scope and policy.
  • HITL/MFA stops a write tool until the approval path is satisfied.

32 / Identity and authorization

Identity and authorization

Ten auth controls in code — from PKCE to ID-JAG.

Login: OAuth 2.0 / OIDC authorization code + PKCE; state and nonce checks.
Session: server-side access, refresh and ID tokens; httpOnly session cookie.
Exchange: RFC 8693 subject-token exchange; optional agent actor / nested act.
Audience: RFC 8707 resource indicator / audience-bound resource token.
Validation: JWT signature/JWKS, RFC 7662 introspection, issuer and scope checks.
Authorization: PingOne Authorize and gateway policy decision; route requires public/user/admin.
Step-up: PingOne MFA/device auth; OTP, Push, FIDO2/WebAuthn/TOTP paths.
Out-of-band: CIBA approval flow for separately configured scenarios.
Intent: PAR + RAR authorization details; DPoP replay demonstrations.
Enterprise MCP: ID-JAG / cross-app access and centralized revocation demos.

40 / Ways to run it

Ways to run it

Four launchers: native, Compose, local K8s, remote K8s.

Native on macOS

./run.sh — BFF, React dev server, MCP server and agent as local Node/Python processes; PingGateway still in Docker. Lightest dev loop; stop/restart/status/tail to manage.

Docker Compose · Docker Desktop or OrbStack

./run-docker.sh — core + RAG by default; start full for everything. Opt-in: spiffe, demo-auth, mcpgw, observability, tracing.

Local Kubernetes · OrbStack or Docker Desktop

Enable K8s, then ./run-k8.sh builds, deploys and port-forwards. OrbStack or Docker Desktop.

Remote Kubernetes + deployment handoffs

AWS EKS: ./run-k8.sh aws-all. Ping SE: ./run-pingaws.sh. Terraform can hand off to an existing namespace.

Also documented: Vercel serverless for the web app (needs Upstash + external WebSocket MCP) — not the full multi-service deployment.

44 / Technical choices visible in code

Design decisions

Six decisions that define the architecture.

Tokens stay with the BFFBrowser gets a session cookie only; the server does exchange and tool authorization.
Known commands stay deterministicHeuristics route known phrases; LLMs handle open text, with fallbacks.
One active agent frameworkLangChain. The others are tested, not active.
Gateway boundaries stay distinctPingGateway default; Node gateway demo; Privilege gateway managed policy + recording.
Run profiles control the footprintRAG, observability, SPIFFE and gateways are profile-selected; experimental services stay out of ordinary runs.
Each data system has a jobLMDB = BFF state · Weaviate = vectors · OpenSearch = MCP search sample. No production bank database.
