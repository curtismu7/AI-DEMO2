# SCOPE_VOCABULARY.md

## Naming convention
  <resource>:<action>

## Standard actions
  read   — non-mutating access
  write  — create / update
  delete — permanent removal
  admin  — unrestricted access (service accounts only)

## Resource prefixes
  accounts     — deposit / credit accounts
  transactions — ledger entries
  profile      — customer identity record
  p1           — PingOne platform built-ins
