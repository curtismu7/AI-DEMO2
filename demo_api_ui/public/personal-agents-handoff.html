Dot Workbench

Verified live 2026-10-20

/personal-agent/dot

Dot is the customer's always-on persona agent: it keeps its own working memory (“call me Sam”, “always book aisle seats”), and the enterprise never governs that memory — only every tool call Dot makes on the user's behalf.

  • Sign in with the credentials above — the page header flips to the signed-in user’s name.
  • Click “Track my latest order” — a governed tool call runs and returns a PERMIT verdict card with the answer.
  • Say “Always keep your answers short” — Dot saves it to its own memory panel (reset is the user's control).
  • Ask “What do you remember about me?” — recall without a tool call.
  • Scroll to “How Dot handles a message” and press Simulate to walk the 10-step flow.

Every page honors the per-page Heuristics | llama.cpp toggle (top right). Heuristics runs with no model call — fast and deterministic for demos; llama.cpp switches in the real model.

Model toggle on every page

Per page, never global

PageAgentModeToggle — top-right of each agent page

Heuristics answers via deterministic keyword routing (no model). llama.cpp runs the real LLM through the governed path. If llama.cpp times out you'll get an explicit “model unavailable — switch to Heuristics” card rather than a silent failure.

Muse — real PingOne agent demo

A standalone app with its own hosted site. Muse is a personal agent that really signs the user in at PingOne (DaVinci, Protect, MFA, agent screen, consent), acts for them with RFC 8693 token exchanges, and reaches the tools through Agent Gateway, Agent Privilege and PingOne Authorize. It is also an OAuth connector for other agents, such as Meta's Muse.

Muse

Verified live 2026-10-28

https://agent-connect.ai-demo.ping-devops.com/

Three paths on one site: Muse acts for Sam, the Airline Connector (another agent asks Muse), and just a user (Sam signs in as himself, no agent, no consent, and his own token is denied at the gateway).

  • Press “Show my airline points”. Muse is turned away with a 401 and PingOne signs Sam in.
  • On the “AI agent detected” screen, the agent name is red when Protect flagged it and blue when only the client ID did, with Protect’s verdict underneath.
  • Back on Muse, the answer shows the points and the claims, with act naming Muse.
  • Press “Sign in as Sam (no agent)” to see the human login and the gateway’s refusal.
  • Open Diagram for the Config tab and three Runtime tabs; press Simulate to walk each one.

United working draft

The customer-facing design document this whole demo stack was built to prove. Written for United's AI and identity teams; every pattern in it runs live on the routes above.

On Users' Personal Agent Design

HTML · PDF · Markdown

docs/personal-agent/ in the repo

MileagePlus, the customer's own agent, and the security between them. Nine-hop flow: discover → register (DCR/CIMD) → consent → per-call RFC 8693 exchange → gateway → Authorize + Protect → transaction-bound HITL approval → permit → audit. Includes the no-BFF/no-DPoP compensating stack, the agent-shape table (native CLI / browser-only / cloud agent), what United has already built, and the Facade's five security controls.

One rule survives as absolute: the member's token is an input to an exchange, never a credential on a tool call.

Demo notes

Verticals change the story, not the mechanics

Switch the vertical (top-left dropdown): Walbuy gives order-status tools, Airline gives seats/miles, Super Banking gives balances and transfers. The governed path is identical — only the tool catalogue and prompt chips change.

Public routes, signed-in runs

All personal-agent pages are public — you can browse them signed out. Signing in (credentials above) is what unlocks live agent runs: tool calls execute under your identity, verdict cards show real decisions, and Dot's memory persists to your account.

If something looks stuck

Know before you demo
  • 403 “Access restricted” right after sign-in: the account needs the hosted-access group — ask the demo owner to re-run the membership step.
  • “The model did not answer” card: llama.cpp is down; flip the toggle to Heuristics and retry.
  • 503 “Service Temporarily Unavailable” on a hosted URL: the hosted SE cluster is scaled down. Use the local links on this page (local.ping-devops.com:4000).
  • Old page after a deploy (404 on assets): hard-refresh the browser.
  • The Reset dot button wipes that user's Dot memory — fine to show, it's the feature.
