Muse — the airline agent

A personal agent that signs the member in at PingOne, then acts for them through Agent Gateway and Privilege. The hosted copy is the real thing: PingOne sign-in, DaVinci, Protect, MFA, consent, token exchange and PingOne Authorize.

Muse (hosted, Real mode)

Real

https://muse.ai-demo.ping-devops.com/

Ask for airline points. Muse is turned away with a 401, sends the member to PingOne, then asks again with a token that names Muse as the actor. On the page the name turns red when PingOne Protect detected the agent and blue when only the client id did.

  • Press Show my airline points, then Continue to PingOne.
  • Sign in with the demo user you were given. The password is not on this page.
  • Accept the consent. Muse answers with the points and tier.
  • Open any step under What Muse did to see the raw request and response.
Run Muse → How it works

Airline Connector (for other agents)

Real

https://muse.ai-demo.ping-devops.com/mcp

The same server is an OAuth custom connector, so an agent such as Meta's Muse can use it. Add it as a custom connector, sign in at PingOne, then ask for points. The page lists the server URL, client id and callback, with copy buttons for the prompts.

  • Server URL https://muse.ai-demo.ping-devops.com/mcp; client id airline-connector; leave the client secret blank.
  • Try “How many airline points do I have?” and “What’s my loyalty status?”.
  • With two airline connectors, name the airline in the prompt so the agent picks the right one.
