ping-mcpgw deployed to namespace {{ .Values.namespace }}.

Check enrollment status:
  kubectl logs -n {{ .Values.namespace }} -l component=ping-mcpgw --tail 40

A clean boot shows "established command stream" with no x509/"Root CA PingOne
Privilege" error. If the pod crash-loops instantly with zero log output before
that line appears, the enrollment JWT is invalid or already consumed — get a
fresh one from Privilege console -> Setup Gateways, then:

  helm upgrade ping-mcpgw ./k8s/helm/mcpgw -n {{ .Values.namespace }} \
    --set-file secrets.envProxyToken=./new-token.jwt \
    --reuse-values

Re-enrollment with a *different* cluster/node identity requires a fresh PVC —
scale to 0, delete the ping-mcpgw-ssl PVC, then upgrade back to replicas 1:
  kubectl scale deployment/ping-mcpgw -n {{ .Values.namespace }} --replicas=0
  kubectl delete pvc ping-mcpgw-ssl -n {{ .Values.namespace }}
  helm upgrade ping-mcpgw ./k8s/helm/mcpgw -n {{ .Values.namespace }} --reuse-values
